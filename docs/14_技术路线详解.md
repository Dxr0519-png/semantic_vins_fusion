# 14 · 语义实现技术路线详解

> 本文是 [`00_项目概述与总体架构`](00_项目概述与总体架构.md) 的深化版,逐层拆解本项目实现语义的技术路线:从 2D 实例分割、动态剔除,到物体级跟踪、对偶二次曲面重建,再到 g2o 联合优化。每层给出原理、数学、实现位置与验证方法,并标注已实现 / TODO 状态。

## 1. 问题定义

传统 VINS-Fusion 在动态场景下有两个根本缺陷:

1. **定位退化**:VINS 基于"静态世界"假设,动态物体(行人、车辆)上的特征点会产生错误的运动约束,使里程计漂移甚至发散;
2. **无语义**:输出只有稀疏点云与轨迹,无法回答"场景里有什么物体、在哪里、多大、是不是同一个"。

**本项目的目标**:在 VINS-Fusion 之上叠加 YOLOv8-seg 实例分割,构建**物体级语义 SLAM** —— 识别并稳定跟踪场景物体,用**对偶二次曲面(椭球)**建立其 3D 表示,通过物体级联合优化同时约束相机位姿与物体参数,最终输出带语义标签的物体地图。

## 4. 分层技术路线详解

### 4.1 感知层:YOLOv8-seg 实例分割

**为什么选实例分割而非纯检测**:mask 是后续所有语义操作的基石 —— 动态点剔除靠"特征点是否落在 mask 内"判断,点-物体关联靠"3D 点是否落在 mask 内"归属。纯 bbox 无法提供像素级归属。

**为什么选 YOLOv8-seg 而非 Mask R-CNN**:工程上 single-stage、易部署、有官方 TensorRT 导出路径,精度对物体级 SLAM 足够(椭球本身是粗粒度近似)。

实现要点([yolo_seg_node.py](../ws_src/yolo_seg_ros/yolo_seg_ros/yolo_seg_node.py)):

1. 订阅 `/camera/color/image_raw`(RealSense 常用 **Best Effort** QoS,丢帧可接受);
2. `model.predict(img, task='segment')` 得到实例列表,每实例含 bbox + mask + 类别 + 置信度;
3. bbox 归一化到 [0,1],mask 按 `mask_scale` 下采样后展平,控制带宽;
4. 推理加速:`.pt` → TensorRT FP16 engine(`export_trt.py`),吞吐提升 2~4 倍;
5. 输出 `/yolo/detections`(`Detection2DArray`),目标帧率 ≥15Hz。

> 模型选择阶梯:`yolov8n-seg`(快)→ `yolov8s-seg`(平衡)→ `yolov8m-seg`(准),先跑通再按精度需求换大。

### 4.2 定位层:VINS-Fusion 的语义服务接口

VINS-Fusion 承担高频视觉惯性状态估计,为语义模块提供三个输入:

| 输入 | 用途 |
|---|---|
| `/keyframe_pose` | 世界系关键帧位姿 → 椭球投影矩阵 P 的构建、马氏门控、联合优化顶点初值 |
| `/keyframe_point` | 世界系 3D 地图点 → 点-物体关联(scale 约束) |
| `/odometry` | 轨迹输出、时间对齐参考 |

本仓库把光流跟踪**内嵌在 estimator 中**(`Estimator::inputImage` 直接调 `featureTracker.trackImage`),原 feature_tracker 节点架构残留的 `inputFeature` 已废弃(`assert(0)`),动态剔除即挂在 `trackImage` 返回之后、进入后端优化之前的位置([estimator.cpp:181](../ws_src/vins_fusion/vins/src/estimator/estimator.cpp#L181))。

### 4.3 动态物体特征点剔除(中间基线,已实现)

**动机**:VINS 假设场景静态。在完整物体级方案之前,先用最朴素的方式验证语义能提升定位 —— 动态类特征点不进后端优化。

**思路**([docs/05](05_动态物体特征点剔除.md)):

```
/yolo/detections ──► vins_node::yolo_callback  ① 按 dynamic_classes 过滤,实例 mask 合并为一张 0/1 图
                        │
                   estimator.inputDynamicMask(t, mask)  ② 存最新 mask(mBuf 保护)
                        │
        Estimator::inputImage ──► trackImage ──► featureFrame
                        │
                        ▼  ③ 取时间最近的 mask(超 dynamic_mask_tolerance 跳过)
        rejectDynamicFeatures: isDynamicPixel 逐点查表
                        │
          ├─ 动态 ──► 剔除 + featureTracker.removeOutliers(复用外点通道)
          └─ 静态 ──► 保留,进入后端优化
```

关键实现:

- `isDynamicPixel(u,v,mask)`:把特征点像素坐标按比例映射到 mask 分辨率查表([feature_tracker.cpp:48](../ws_src/vins_fusion/vins/src/featureTracker/feature_tracker.cpp#L48));
- **复用外点通道**:后端 `outliersRejection` 原本就通过 `removeIndex` → `FeatureManager::removeOutlier` + `FeatureTracker::removeOutliers` 清理坏点;动态剔除复用同一套 `FeatureTracker::removeOutliers`([estimator.cpp:304](../ws_src/vins_fusion/vins/src/estimator/estimator.cpp#L304)),区别只是动态 id 由 mask 判定而非重投影误差;
- 动态类集合由 VINS 配置 `dynamic_classes` 决定,`dynamic_remove` 开关可切换基线与剔除两种模式。

> ⚠️ **已知近似**:YOLO 跑在彩色流,特征来自红外流,两者 FOV 不同,`isDynamicPixel` 按"同一 FOV"做归一化映射属于中间基线近似。严格做法是 `rs2::align` 把 mask 重投影到红外系(见 docs/05 §3 与 docs/07 进阶工作)。

### 4.4 物体级数据关联与跟踪(已实现)

**目标**:判断"这帧的检测 A 和上帧的检测 B 是不是同一个物体",维护跨帧稳定的 `track_id`。这是多帧重建的前提。

**匹配线索**(从易到难):

1. **类别一致(硬约束)**:class 不同直接不匹配(代价 inf);
2. **bbox IoU(主线索)**:相邻帧同一物体的 bbox 重叠度高;
3. **马氏距离门控(已实现,几何线索)**:见下文;
4. **3D 点投影落入 mask(TODO)**:VINS 点投影到当前帧,落入检测 mask 的比例作为几何一致性加分项。

**马氏距离门控**(docs/06 §3.4,已实现):

对每个有"正椭球"的 track,用当前帧投影矩阵 `P = K[R_wc|t_wc]` 预计算投影椭圆:

```
C* = P·Q*·Pᵀ         对偶锥
C  = C*⁻¹            原始锥(图像中的椭圆)
椭圆中心 μ 与协方差 Σ ← ellipseFromConic 提取
预测点 = dehom(P·[c;1])   (c 为椭球中心)
d_M² = (z-μ)ᵀΣ⁻¹(z-μ)     z = 检测 bbox 中心像素
门控: d_M² < χ²₂ (=5.991) 才允许匹配
```

数学上,投影椭圆轮廓恰是"**单位马氏距离**"等值线 `(u-μ)ᵀΣ⁻¹(u-μ)=1`,所以 χ²₂ 门控天然对应"检测中心落在椭球投影轮廓内"。新 track 的种子锥是秩 3 退化锥,`isProper()` 排除后跳过门控,退化为纯 IoU 关联。

**匹配算法**:贪心最近邻 —— 对每个 track 取通过两道门控且代价最小的未占用检测。匈牙利算法(全局最优)留作 TODO。

**生命周期管理**([object_map.cpp](../ws_src/object_slam/src/object_map.cpp)):

| 机制 | 实现 |
|---|---|
| 出生 | 未匹配检测 → 新 track(`observations >= min_observations(3)` 才输出) |
| 消亡 | 超过 `max_missed_frames(30)` 未观测 → 删除 |
| 短暂遮挡 | 未匹配不立即删,超期才 `prune`;存活 track 全部参与关联,重现能找回原 id |
| id 复用 | `add` 优先从空闲列表取被回收的 id,避免与现存 id 冲突 |
| 分割抖动 | track 的 bbox 做 EMA 平滑(`ema_alpha=0.7`)再用于关联 |

### 4.5 对偶二次曲面物体重建(已实现)

#### 4.5.1 为什么是"对偶二次曲面"

| 表示 | 优点 | 缺点 |
|---|---|---|
| 点云簇 | 简单 | 无参数化、难优化、噪声大 |
| 3D cuboid | 直观可度量 | 8 角点估计难、退化解多 |
| **对偶二次曲面(椭球)** | 9 自由度、bbox 反投影锥可直接初始化、可写进因子图 | 椭球近似,细节损失 |

决定性优势:**对偶形式投影后直接得到图像中的椭圆,椭圆切线恰对应 bbox 四边** —— 检测框 → 3D 椭球的几何约束关系是解析、干净的,非常适合因子图优化。这也是 QuadricSLAM / SO-SLAM / OA-SLAM 的共同选择。

#### 4.5.2 数学基础

**原始二次曲面** Q(4×4 对称矩阵):齐次点 `x̃=[x,y,z,1]ᵀ` 在曲面上 ⇔ `x̃ᵀ Q x̃ = 0`。

**对偶二次曲面** Q* = adj(Q)(满秩时 ∝ Q⁻¹):平面 π 与曲面相切 ⇔ `πᵀ Q* π = 0`。

**椭球参数化**(9 DOF):中心 c、半轴 r=(rx,ry,rz)、旋转 R:

```
T = [ R  c ]         Q* = T · diag(rx², ry², rz², -1) · Tᵀ
    [ 0  1 ]
```

**投影**(世界 → 图像):

```
对偶锥  C* = P Q* Pᵀ     (3×3 对称)
原始锥  C  = C*⁻¹        (图像中的椭圆,齐次归一化)
```

**从投影椭圆提取中心/协方差**(马氏门控用):C 的齐次块形式为

```
C = [ Σ⁻¹,     -Σ⁻¹μ ]
    [ -(Σ⁻¹μ)ᵀ, μᵀΣ⁻¹μ - 1 ]   (任意尺度)
```

中心 `μ = (ch₀/ch₂, ch₁/ch₂)`,其中 `ch = C⁻¹·[0,0,1]ᵀ`(无穷远线关于 C 的极点);协方差 `Σ = -f₀·Q⁻¹`,`Q = C[0:2,0:2]`,`f₀ = [μ;1]ᵀ·C·[μ;1]`(等价于 Q 特征分解后半轴平方 `sᵢ² = -f₀/λᵢ`)。对应 `ellipseFromConic`([quadric.cpp:67](../ws_src/object_slam/src/quadric.cpp#L67))。

**分解**(Q* → 中心/半轴/姿态):归一化使 `Q*(3,3)=-1`,中心 `c = -Q*[0:3,3]`,`RSRᵀ = Q*[0:3,0:3] + c·cᵀ`,对 RSRᵀ 特征分解得半轴与旋转([quadric.cpp:130](../ws_src/object_slam/src/quadric.cpp#L130))。

#### 4.5.3 初始化:单帧 bbox 反投影锥

一帧观测无法唯一确定椭球(深度未知),只能得到**顶点在相机光心的锥**:

1. bbox 四边写成齐次直线:`l_left=(1,0,-x1)` 等;
2. 与四边相切的对偶锥(Cross & Zisserman):
   ```
   C* = l_left·l_rightᵀ + l_right·l_leftᵀ + l_top·l_bottomᵀ + l_bottom·l_topᵀ
   ```
3. 反投影到世界:`Q* = Pᵀ C* P`(秩 3 退化锥,仅作初值)。

对应 `fromBBoxCone`([quadric.cpp:31](../ws_src/object_slam/src/quadric.cpp#L31))。

#### 4.5.4 多视图最小二乘精化(SVD)

同一物体 K 帧观测,每帧 bbox 四边给出 4 个切平面约束 `πᵢᵀ Q* πᵢ = 0`。令 `m = Pᵀ l`,约束化为对 Q* 上三角 10 元的**线性方程**,堆叠:

```
M ∈ R^(4K × 10),  M x = 0
```

最小二乘解 = M 的**最小右奇异向量**(JacobiSVD)。再施加尺度规范 `Q*(3,3)=-1` 并投影到半正定锥(非正定则钳制半径),保证得到正椭球。单视图/退化时回退为 `fromBBoxCone` 锥。

对应 `refineSingleObject`([quadric_optimizer.cpp:201](../ws_src/object_slam/src/quadric_optimizer.cpp#L201))。

> **为什么 SVD 而不是迭代优化**:约束对 Q* 是线性的,最小二乘解闭式可得,快速且无初值问题;非线性的精化交给下游 g2o。

#### 4.5.5 点-物体关联(scale 约束,已实现)

VINS 世界系 3D 点(`/keyframe_point`)归属到物体:

1. node 缓存世界点([object_slam_node.cpp:171](../ws_src/object_slam/src/object_slam_node.cpp#L171) `pointsCallback`);
2. 联合优化前用 `signedDistance` **最近邻**把点归属到物体(阈值 0.5,每物体 ≤30 个点,`associatePointsToObjects`);
3. 归属点作为 `EdgePointQuadric` 约束进入 g2o。

`signedDistance` 是马氏距离近似([quadric.cpp:152](../ws_src/object_slam/src/quadric.cpp#L152)):

```
n = (Rᵀ(p-c)) ./ r;   d = ‖n‖ - 1   // <0 在椭球内
```

### 4.6 物体级联合优化(g2o 因子图,已实现)

#### 4.6.1 与 VINS 后端的关系(解耦设计)

VINS 已有完整滑动窗口后端,**不重复造轮子**。物体级优化以 VINS 输出为初值/先验,做一层低频轻量联合优化:

| 层 | 频率 | 作用 |
|---|---|---|
| VINS 后端 | 高频 | 视觉惯性状态估计,输出位姿 + 点云 |
| 物体级优化 | 低频(每 20 帧) | 联合优化物体椭球 + 微调关键帧位姿 |

#### 4.6.2 因子图结构

```
顶点:
  VertexSE3       相机位姿 T_wc,初值来自 VINS
  VertexQuadric   物体对偶二次曲面 Q*(9 参数,上三角不含 (3,3),尺度规范 (3,3)≡-1)

边:
  EdgeQuadricBBox   bbox 四边 vs 椭球投影对偶锥的切平面代数距离(主约束)
  EdgeSE3Prior      SE3 位姿先验,信息矩阵 = 先验权重(防止物体把位姿拉偏)
  EdgePointQuadric  点-椭球约束,误差 = max(0, signedDistance(p))(只惩罚外部点,防拉缩)
```

**主约束 EdgeQuadricBBox**([quadric_optimizer.cpp:116](../ws_src/object_slam/src/quadric_optimizer.cpp#L116)):

椭球 Q* 经 P 投影为图像对偶锥 C*,bbox 四边 `l_k` 与 C* 的切平面代数距离即误差:

```
e_k = l_kᵀ C* l_k        (C* = P Q* Pᵀ,归一化)
```

边类型 `BaseBinaryEdge<4, Vector4d, VertexQuadric, VertexSE3>`,误差在**归一化图像坐标**下计算保证 LM 稳定;雅可比用数值中心差分(quadric 9 参数 + SE3 6 参数)。

**实现关键点**:

- g2o 无现成 quadric 顶点/边,全部自定义;
- **quadric 顶点必须 `setMarginalized(true)` 走 Schur 补**(9×9 landmark 块),否则 g2o 按 6×6 pose 块处理会崩溃 —— 这是本项目落地时踩过的关键坑;
- 求解器:`BlockSolver<BlockSolverTraits<6,9>>` + `LinearSolverEigen` + Levenberg-Marquardt。

#### 4.6.3 求解流程

```
每 optimize_interval(默认 20)帧触发:
  1. 收集窗口内关键帧位姿 + 对应 bbox 观测
  2. 建图:addVertex(位姿) / addVertex(quadric) / addEdge(...)
  3. 固定第一个关键帧位姿(消除 gauge 自由度)
  4. optimizer.optimize(N)   # LM
  5. 回写:更新 map 里的 Q*,更新关键帧位姿
```

**动态物体处理**:对"确实运动"的物体(行人),bbox 约束不可靠,应只跟踪不参与位姿联合优化,或降低其信息矩阵权重(现状:配置开关留待验证)。

## 9. 一句话总结

**技术路线 = YOLOv8-seg 提供 2D 语义 → 跨帧数据关联得到稳定 track → bbox 反投影锥初始化 + 多视图 SVD 精化得到 3D 椭球 → g2o 因子图中椭球与位姿联合 BA → 输出带语义标签的物体地图**。全程以"**椭球投影的切线 = bbox 边**"这一解析几何关系为纽带,使 2D 检测与 3D 重建闭环、物体约束与相机位姿相互校正 —— 这是物体级语义 SLAM(QuadricSLAM / SO-SLAM / OA-SLAM 路线)的标准范式,也是本项目从"能定位"走向"理解场景"的关键跃迁。
