# 08 · 物体级联合优化（g2o 因子图）

## 1. 目标

把"相机位姿"和"物体椭球"放进同一个**因子图**做联合优化（BA），让物体约束反过来校正相机位姿，同时用多帧观测精化物体参数，输出全局一致的轨迹 + 物体地图。

## 2. 与 VINS 后端的关系（解耦设计）

VINS-Fusion 已有完整的滑动窗口后端，**不重复造轮子**。物体级优化以 VINS 输出为**初值/先验**，做一层轻量联合优化：

| 层 | 作用 |
|---|---|
| VINS 后端 | 高频视觉惯性状态估计，输出位姿 + 点云 |
| 物体级优化（本章） | 低频（按关键帧批量），联合优化物体椭球 + 微调关键帧位姿 |

这样既能利用 VINS 的鲁棒性，又能引入物体级约束。

## 3. 因子图结构

```
顶点（Vertex）：
  VertexSE3       相机位姿 T_wc（世界->相机），初值来自 VINS
  VertexQuadric   物体对偶二次曲面 Q*（9 参数）

边（Edge）：
  EdgeQuadricBBox   检测 bbox 与 Q* 投影椭圆的几何误差（主约束）
  EdgeSE3Prior      VINS 位姿先验（信息矩阵 = VINS 协方差逆）
  EdgePointQuadric  点-物体关联约束（mask 内 3D 点落在椭球上）
```

### 3.1 EdgeQuadricBBox（核心）

物体 Q* 投影到图像得到椭圆 C（`projectPrimal`），其**外接矩形**应与检测 bbox 贴合。定义 4 个角点误差：

```
对 bbox 的 4 个角点 p_k，椭圆 C 满足 p_kᵀ C p_k = 0
误差 e_k = p_kᵀ C p_k / 尺度归一化
```

在 g2o 里实现自定义边 `EdgeQuadricBBox`，其中顶点是 Q*（9 参数）+ 位姿 T_wc（二元边），误差取 bbox 四边对投影**对偶锥**的切平面代数距离。

> ✅ **已实现**：`EdgeQuadricBBox : BaseBinaryEdge<4, Vector4d, VertexQuadric, VertexSE3>`（[quadric_optimizer.cpp](../ws_src/object_slam/src/quadric_optimizer.cpp#L116-L189)）。误差 `e_k = l_kᵀ C* l_k`（`C* = P Q* Pᵀ` 归一化，`l_k` 为 bbox 四边单位法向线，**归一化图像坐标**下计算以保证 LM 稳定）；雅可比用数值中心差分（quadric 9 参数 + SE3 6 参数）。顶点 `VertexQuadric : BaseVertex<9, Matrix4d>`（[L76-L92](../ws_src/object_slam/src/quadric_optimizer.cpp#L76-L92)，9 参数 = 上三角不含 (3,3)，`(3,3)≡-1` 尺度规范）。

### 3.2 EdgeSE3Prior

```
e = log(T_wc⁻¹ · T_vins)   （SE3 上的先验误差）
```

防止物体约束把位姿拉偏；信息矩阵来自 VINS 位姿的估计不确定性。

> ✅ **已实现**：`EdgeSE3Prior : BaseUnaryEdge<6, Isometry3d, VertexSE3>`（[quadric_optimizer.cpp](../ws_src/object_slam/src/quadric_optimizer.cpp#L197-L208)），右不变误差 `e = toVectorMQT(T_est · T_prior⁻¹)`，雅可比取单位阵近似（先验附近线性化）。信息矩阵标量 `pose_prior_weight`（默认 1.0，见 [quadric_optimizer.h](../ws_src/object_slam/include/object_slam/quadric_optimizer.h#L29-L35)）。

### 3.3 EdgePointQuadric

对属于物体 i 的 3D 点 p：

```
e = p̃ᵀ Q p̃   （Q 为原始二次曲面 = Q*⁻¹，落在曲面上应为 0）
```

或直接用 `signedDistance` 的误差形式。

> ✅ **已实现**：`EdgePointQuadric : BaseUnaryEdge<1, double, VertexQuadric>`（[quadric_optimizer.cpp](../ws_src/object_slam/src/quadric_optimizer.cpp#L213-L255)），误差取 `max(0, signedDistance(p))`——只惩罚椭球外部的点，防止椭球被拉缩。

> ✅ **已实现**（[quadric_optimizer.cpp](../ws_src/object_slam/src/quadric_optimizer.cpp#L321-L430)）：`VertexQuadric`、`EdgeQuadricBBox`、`EdgeSE3Prior`、`EdgePointQuadric` 均已定义；`QuadricOptimizer::optimize` 用 `BlockSolver<BlockSolverTraits<6,9>>` + `LinearSolverEigen` + `OptimizationAlgorithmLevenberg` 求解。**关键点**：quadric 顶点必须 `setMarginalized(true)` 走 Schur 补（9×9 landmark 块），否则 g2o 会按 6×6 pose 块处理而崩溃。

> 参考：QuadricSLAM / OA-SLAM 的开源实现，以及 g2o 官方 `g2o/types/slam3d` 里自定义顶点/边的写法。

## 5. 求解流程

```
每次触发优化（如每 10 个关键帧）：
  1. 收集窗口内关键帧位姿 + 对应 bbox 观测
  2. 建图：addVertex(位姿) / addVertex(quadric) / addEdge(...)
  3. 固定第一个关键帧位姿（消除 gauge 自由度）
  4. optimizer.optimize(N)   # Levenberg-Marquardt
  5. 回写：更新 map 里的 Q*，更新关键帧位姿
```

> ✅ **已实现**：`QuadricOptimizer::optimize`（[quadric_optimizer.cpp](../ws_src/object_slam/src/quadric_optimizer.cpp#L319-L430)）按上述 5 步建图求解：建 SE3 顶点+先验边、建 quadric 顶点、加 bbox 边、加点边、固定首帧、LM 求解、回写 map 与位姿。node 每 `optimize_interval`（默认 20）帧触发（[object_slam_node.cpp](../ws_src/object_slam/src/object_slam_node.cpp#L124-L126) 调 `runJointOptimization`，[L189-L232](../ws_src/object_slam/src/object_slam_node.cpp#L189-L232)）。

## 6. 与 VINS 位姿的一致性

- **初值**：quadric 顶点用 `refineSingleObject`（docs/07 §4）的结果初始化，避免局部最优。
- **信息矩阵**：VINS 位姿先验的信息矩阵要合理，否则物体约束会过度拉偏位姿。
- **动态类**：对"确实运动"的物体（如行人），其 bbox 约束不可靠，应**只做跟踪、不参与位姿联合优化**，或降低其信息矩阵权重。

## 7. 验证

- **单元测试（无需硬件）**：[tests/test_quadric.cpp](../ws_src/object_slam/tests/test_quadric.cpp) 验证：差初值（尺度 0.8、中心偏移 0.15m）下联合优化椭球误差下降 >50%；好初值（refineSingleObject 结果）下优化后位姿漂移 ~0、椭球保持准确。
  ```bash
  colcon build --packages-select object_slam
  ./build/object_slam/test_quadric          # 期望全部通过（exit 0）
  ```
- **定量**：固定标定物场景下，优化后物体中心/半轴误差应小于仅重建（docs/07）的结果。
- **定性**：轨迹与物体椭球在 rviz 里与真实场景几何一致，物体与背景无漂移错位。
- **对比**：关掉物体约束（纯 VINS）vs 开启联合优化，比较 ATE/RPE（见 docs/10）。

## 8. 常见问题

| 现象 | 排查 |
|---|---|
| 优化后物体飞掉 | 初值差 / 信息矩阵不合理 / 观测太少；先 fix 位姿只优化物体 |
| 收敛慢 | 用解析雅可比替代数值差分；减少窗口内顶点数 |
| 位姿被物体带偏 | 加强 EdgeSE3Prior 信息矩阵，或对动态物体不参与联合优化 |
