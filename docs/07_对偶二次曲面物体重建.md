# 07 · 对偶二次曲面物体重建

## 1. 目标

把多帧 2D 分割观测（bbox + mask）重建为物体的 3D 表示——**对偶二次曲面（椭球）**，得到中心、三轴半径、姿态。

## 2. 数学基础

### 2.1 二次曲面与对偶

一个 3D 二次曲面 Q 是 4×4 对称矩阵，齐次点 `x̃ = [x,y,z,1]ᵀ` 在曲面上当且仅当：

```
x̃ᵀ Q x̃ = 0
```

**对偶二次曲面** Q* 是其伴随矩阵（满秩时 Q* ∝ Q⁻¹），满足：平面 π 与曲面相切 当且仅当

```
πᵀ Q* π = 0
```

用对偶形式的好处：**相机投影后直接得到图像里的对偶锥（椭圆）**，与 2D bbox 天然对应。

### 2.2 椭球的参数化（9 自由度）

中心 c、三轴半径 r=(rx,ry,rz)、旋转 R，构造：

```
T = [ R  c ]
    [ 0  1 ]

Q* = T · diag(rx², ry², rz², -1) · Tᵀ
```

对应代码 `DualQuadric::fromEllipsoid`（[quadric.cpp](../ws_src/object_slam/src/quadric.cpp#L15-L29)）。

### 2.3 投影：椭球 → 图像椭圆

给定相机投影矩阵 P（3×4，世界→像素）：

```
对偶锥  C* = P Q* Pᵀ     （3×3 对称）
原始锥  C  = C*⁻¹        （即图像中的椭圆，齐次归一化）
```

对应 `projectDual` / `projectPrimal`（[quadric.cpp](../ws_src/object_slam/src/quadric.cpp#L51-L65)）。**椭圆的四条切线**对应物体 bbox 的四条边，这是优化的核心几何约束。

**从投影椭圆提取 2D 中心与协方差**（马氏距离门控用，docs/06 §3.4）：原始锥 C 表示椭圆 `(u-μ)ᵀΣ⁻¹(u-μ) = 1`，其齐次块形式为 `C = [Σ⁻¹, -Σ⁻¹μ; -(Σ⁻¹μ)ᵀ, μᵀΣ⁻¹μ-1]`（任意尺度），故可解出：

```
中心   μ = (ch₀/ch₂, ch₁/ch₂),  ch = C⁻¹·[0,0,1]ᵀ    // 无穷远线关于 C 的极点
协方差 Σ = -f₀·Q⁻¹， Q = C[0:2,0:2]， f₀ = [μ;1]ᵀ·C·[μ;1]
       （等价地：Q 特征分解后半轴平方 sᵢ² = -f₀/λᵢ，Σ = R·diag(s₁²,s₂²)·Rᵀ）
```

投影椭圆轮廓恰为**"单位马氏距离"等值线**。对应 `DualQuadric::ellipseFromConic`（[quadric.cpp](../ws_src/object_slam/src/quadric.cpp#L67-L96)）；`projectedEllipse`（[L98-L114](../ws_src/object_slam/src/quadric.cpp#L98-L114)）先做 det/finite 守卫再反演，退化投影返回 false 不产生 NaN。

### 2.4 分解：Q* → 中心/半轴/姿态

由 Q* 的结构（§2.2）可反解：

```
归一化使 Q*(3,3) = -1
中心   c = -Q*[0:3, 3]
RSRᵀ = Q*[0:3, 0:3] + c·cᵀ
对 RSRᵀ 做特征分解：半轴 = sqrt(特征值)，R = 特征向量
```

对应 `DualQuadric::decompose`（[quadric.cpp](../ws_src/object_slam/src/quadric.cpp#L130-L150)）。

## 3. 初始化：单帧 bbox 反投影锥

只有一帧观测时，无法唯一确定椭球（深度未知），只能得到**顶点在相机光心的锥**：

1. bbox 四条边（像素坐标）写成齐次直线：
   ```
   l_left=(1,0,-x1)  l_right=(1,0,-x2)  l_top=(0,1,-y1)  l_bottom=(0,1,-y2)
   ```
2. 与四条边相切的对偶锥（Cross & Zisserman 公式）：
   ```
   C* = l_left·l_rightᵀ + l_right·l_leftᵀ + l_top·l_bottomᵀ + l_bottom·l_topᵀ
   ```
3. 反投影到世界：
   ```
   Q* = Pᵀ C* P        （秩 3 的退化锥）
   ```

对应 `DualQuadric::fromBBoxCone`（[quadric.cpp](../ws_src/object_slam/src/quadric.cpp#L31-L49)）。此 Q* 是**退化**的（锥，不是椭球），仅作初值，需多视图精化。

## 4. 多视图最小二乘精化

对同一物体的 K 个观测，每个观测的 bbox 四条边给出 4 个切平面约束 `πᵢᵀ Q* πᵢ = 0`。

把 Q* 的 9 个独立元素排成向量 x，每个约束是 x 的**线性方程** `aᵢᵀ x = 0`，堆叠成：

```
A x = 0，  A ∈ R^(4K × 9)
```

最小二乘解 = A 的**最小奇异值对应的右奇异向量**（SVD）。再施加椭球约束（把退化解投影到半正定锥）得到正椭球。

> ✅ **已实现**：`QuadricOptimizer::refineSingleObject`（[quadric_optimizer.cpp](../ws_src/object_slam/src/quadric_optimizer.cpp#L201-L268)）。实现要点：
> 1. 每观测的 4 条 bbox 边 → 令 `m = Pᵀ l`，约束 `mᵀ Q* m = 0`，对 Q* 的上三角 10 元线性化；
> 2. 堆叠成 `M ∈ R^(4K×10)`，`JacobiSVD` 取最小右奇异向量；
> 3. 尺度规范 `Q*(3,3) = -1`，并投影到半正定锥（非正定则钳制半径重建为正椭球）；
> 4. 单视图/退化时回退为 `fromBBoxCone` 锥（docs/07 §3）。
>
> 观测由 `Tracker` 累积（[tracker.cpp](../ws_src/object_slam/src/tracker.cpp#L64-L79) 的 `pushObservation`），node 每帧驱动精化（[object_slam_node.cpp](../ws_src/object_slam/src/object_slam_node.cpp#L124) 调 `refineObjects`，[L184-L190](../ws_src/object_slam/src/object_slam_node.cpp#L184-L190)）。

## 5. 点-物体关联（几何约束）

VINS 提供世界系 3D 地图点（实际话题 `/keyframe_point`，类型 `sensor_msgs/PointCloud`；若 object_slam 需要 `/vins_fusion/map_points`，对 vins 节点做话题重映射即可）。把点投影到物体所在帧：

1. 若点投影落入该物体的 mask → 该点属于此物体；
2. 对每个物体的 3D 点集合，用 `DualQuadric::signedDistance` 计算点到椭球的归一化距离，构造**点-椭球几何误差**，作为额外约束加入优化（docs/08）。

```cpp
double DualQuadric::signedDistance(const Vector3d& p) const {
  decompose(c, r, R);
  Vector3d n = (Rᵀ (p - c)).array() / r.array();
  return n.norm() - 1.0;   // <0 内部
}
```

> 📄 **源码出处**：[quadric.cpp](../ws_src/object_slam/src/quadric.cpp#L152-L159) 的 `DualQuadric::signedDistance`（马氏距离近似）。

> ✅ **已实现（mask 投影待 docs/07 §5 后续精化）**：
> - node 订阅 `/keyframe_point`（`sensor_msgs/PointCloud`，VINS vins_node 发布）缓存世界系 3D 点（[object_slam_node.cpp](../ws_src/object_slam/src/object_slam_node.cpp#L171-L182) `pointsCallback`）；
> - 联合优化前用 `signedDistance` 最近邻把点归属到物体（阈值 0.5，每个物体 ≤30 个点，[object_slam_node.cpp](../ws_src/object_slam/src/object_slam_node.cpp#L228-L250) `associatePointsToObjects`）；
> - 归属的点作为 `EdgePointQuadric` 约束加入 g2o（docs/08 §3.3）。
>
> "点投影落入 mask → 属于该物体"的 mask 方案（本 § 第 1 条）暂未实现（需把 InstanceMask 反投影回世界，留作 TODO）。

## 7. 验证

- **单元测试（无需硬件）**：[tests/test_quadric.cpp](../ws_src/object_slam/tests/test_quadric.cpp) 合成"真实椭球 → 多视角投影 → 精确切线 bbox"观测，验证 `refineSingleObject` 恢复真实中心/半轴、单视图退化不崩溃、g2o 联合优化收敛。
  ```bash
  colcon build --packages-select object_slam
  ./build/object_slam/test_quadric          # 期望全部通过（exit 0）
  ```
- **几何验证**：把重建椭球投影回图像，观察其外接椭圆与 YOLO bbox 是否贴合。
- **尺度验证**：用已知尺寸物体（如 40×30×20 cm 箱子），比较重建半轴与真实尺寸（相对误差 < 10%）。
- **收敛验证**：随着观测帧数增加，椭球中心/半轴应趋于稳定（方差下降）。

## 8. 常见问题

| 现象 | 排查 |
|---|---|
| 椭球尺度发散 | 观测视角不足（缺少深度变化），需多视角观测；或用 mask 内 3D 点约束尺度 |
| 椭球退化成锥 | 未施加椭球约束（§4 的投影到半正定锥步骤缺失） |
| 中心漂移 | bbox 与 mask 时间未对齐（见 docs/04），或投影矩阵 P 的外参不准 |
