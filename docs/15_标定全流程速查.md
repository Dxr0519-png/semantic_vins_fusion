# 15 · 标定全流程速查（录制 → 标定 → 落地）

> **一句话**：Jetson 录 3 份 bag → rosbags 转 ROS1 → 拷到 PC 用 kalibr 标 → 结果拷回 Jetson 填 3 处配置 → 分阶段重启验证。
> 本速查是**操作版**（照抄命令即可），原理与细节见 [docs/04](04_传感器时间同步与内外参标定.md)。
> 话题前缀为**单层 `/camera/...`**（[rs_camera.launch.py](../ws_src/vins_fusion/vins/launch/rs_camera.launch.py) 已设 `camera_namespace: '/'`）。

## 2. Jetson 端：录制

### 2.1 启动相机（3 终端）

```bash
# ── 终端1：启动相机（必须用封装版，裸 rs_launch 默认不开 IMU/infra）──
source /opt/ros/humble/setup.bash && source $WS/install/setup.bash
ros2 launch vins rs_camera.launch.py

# ── 终端2：确认话题有数据（再开始录）──
ros2 topic list | grep camera      # 单层前缀：/camera/imu、/camera/infra1|2/image_rect_raw、/camera/color/image_raw
ros2 topic hz /camera/imu          # ~199Hz（accel 101 + gyro 200 融合）
ros2 topic hz /camera/infra1/image_rect_raw    # ~30Hz

# ── 终端3：预览，保证标定板始终在画面内 ──
ros2 run rqt_image_view rqt_image_view /camera/infra1/image_rect_raw
```

### 2.2 录 3 份 bag

| bag | 话题 | 时长 | 用途 |
|---|---|---|---|
| `calib_cam` | infra1 + infra2 | 1~2 分钟 | 内参复标（可选，有出厂值可跳过 §5.2） |
| `imu_cam` | color + infra1 + infra2 + imu | 2~3 分钟 | 外参标定（**核心**） |
| `imu_static` | imu | 静止 2 小时 | IMU 噪声标定（可选） |

```bash
ros2 bag record -o calib_cam /camera/infra1/image_rect_raw /camera/infra2/image_rect_raw
ros2 bag record -o imu_cam /camera/color/image_raw /camera/infra1/image_rect_raw \
  /camera/infra2/image_rect_raw /camera/imu
ros2 bag record -o imu_static /camera/imu
```

录完检查消息数与时长相符：`ros2 bag info imu_cam`

### 2.3 imu_cam 动作要诀（质量关键）

**分 5 段**（全程慢、平滑、充分激励 IMU 六自由度）：

| 阶段 | 时长 | 动作 |
|---|---|---|
| ① 静止 | 5~10 s | 相机不动，正对标定板（估计 bias 与重力方向） |
| ② 水平 8 字 | 30~40 s | 横卧 ∞ 轨迹 |
| ③ 竖直 8 字 | 30~40 s | 竖立 ∞ 轨迹 |
| ④ 8 字 + 自旋 | 30~40 s | 水平 8 字 + 绕光轴缓慢拧手腕 90°~180° |
| ⑤ 静止 | 3~5 s | 收尾 |

**禁忌**：只做纯平移（陀螺仪无激励 → 外参旋转不可观）、只绕单轴、急停急转、标定板出画面/遮挡、板太小/光照反光。
> 标定板固定、手持相机移动比移动板更稳。走一个 ∞ 约 5~10 s，全程保持画面里有棋盘格。

## 3. Jetson 端：rosbag2 → ROS1

```bash
pip install "rosbags==0.9.23"   # 锁 0.9.x：新版本(0.10+)CLI 改为 --src/--dst 且不再支持输出 ROS1 .bag
rosbags-convert calib_cam      # 逐个转换，生成同名 .bag
rosbags-convert imu_cam
rosbags-convert imu_static
```

## 4. 拷贝到 PC（4 个文件）

| 文件 | 来源 |
|---|---|
| `imu_cam.bag` | §3 转换产物 |
| `calib_cam.bag` | §3（若标内参） |
| `imu.yaml` | 模板见 [§5.3](#53-外参--时延)，`rostopic: /camera/imu` + `update_rate: 199` |
| `april_6x6.yaml` | 标定板定义（tagSize 与你打印的板一致） |

```bash
# PC 上拉取（IP 换成板子 IP）
mkdir -p ~/calib && cd ~/calib
scp zc@<板子IP>:~/imu_cam.bag zc@<板子IP>:~/calib_cam.bag zc@<板子IP>:~/imu.yaml zc@<板子IP>:~/april_6x6.yaml .
```

## 5. PC 端：kalibr 标定

### 5.1 环境（一次性）

```bash
# Ubuntu 24 需 Docker；起容器并把 kalibr 源码与 /data 挂进去
docker run -it -v ~/kalibr:/kalibr_src -v $(pwd):/data ros:noetic-ros-base-focal bash

# 容器内编译 kalibr（依赖 + 编译约 15 分钟，完整命令见 docs/04 §6.2③）
# catkin build 完成后 source devel/setup.bash
```

### 5.2 内参（可选）

```bash
kalibr_calibrate_cameras --bag /data/calib_cam.bag \
  --topics /camera/infra1/image_rect_raw /camera/infra2/image_rect_raw \
  --models pinhole-radtan pinhole-radtan --target /data/april_6x6.yaml
```

输出 `camchain-*.yaml`（fx/fy/cx/cy + k1k2p1p2），重投影误差应 < 0.5 px。

### 5.3 外参 + 时延

`imu.yaml` 模板（噪声值填 imu_utils 结果，未跑则用 [config/d435i/imu.yaml](../config/d435i/imu.yaml) 现值）：

```yaml
rostopic: /camera/imu
update_rate: 199            # 融合 IMU 实测频率
gyroscope_noise_density: 0.001
gyroscope_random_walk: 0.00001
accelerometer_noise_density: 0.01
accelerometer_random_walk: 0.0001
```

```bash
kalibr_calibrate_imu_camera --bag /data/imu_cam.bag \
  --cam /data/camchain-*.yaml --imu /data/imu.yaml \
  --target /data/april_6x6.yaml
# 时延(td)标定：新版 kalibr（GitHub master）默认开启，无需 --time-calibration（旧版才需要该参数）
```

输出 `imu-cam-*.yaml`：**`T_ci`**（相机→IMU 外参，即 body_T_cam0）、**`td`**（相机-IMU 时间偏移）。

## 6. 落地到 Jetson（3 处）

```bash
# PC → Jetson 拷结果（IP 换成板子 IP）
scp camchain-*.yaml imu-cam-*.yaml zc@<板子IP>:~/
```

### 6.1 ① VINS 配置（改完重启节点即生效，**无需编译**）

目录 `ws_src/vins_fusion/config/realsense_d435i/`：

| 标定输出 | 填到 | 说明 |
|---|---|---|
| camchain 左目内参 | [left.yaml](../ws_src/vins_fusion/config/realsense_d435i/left.yaml) | fx/fy/cx/cy/k1k2p1p2；**分辨率必须 640x480** |
| camchain 右目内参 | [right.yaml](../ws_src/vins_fusion/config/realsense_d435i/right.yaml) | 同上 |
| `imu-cam-*.yaml` 的 `T_ci` | [realsense_stereo_imu_config.yaml](../ws_src/vins_fusion/config/realsense_d435i/realsense_stereo_imu_config.yaml) 的 `body_T_cam0` | **先求逆再填**：`body_T_cam0 = inv(T_ci)`，4x4 行主序（⚠️ 见下方警告） |
| `imu-cam-*.yaml` 的 `T_cam1_imu0` | `body_T_cam1` | 同样求逆填入（kalibr 已直接给出 cam1 的 T_ci，无需自己乘） |
| imu_utils 结果 | `acc_n` / `gyr_n` / `acc_w` / `gyr_w` | 四行噪声 |
| `imu-cam-*.yaml` 的 `td` | `td` | **符号注意**：VINS 定义「图像戳 + td = IMU 戳」；不确定就试两个符号，`estimate_td` 会在线微调 |

`body_T_cam0` 格式（kalibr 的 T_ci **求逆后**按行序填入）：

```yaml
body_T_cam0: !!opencv-matrix
   rows: 4
   cols: 4
   dt: d
   data: [ r00, r01, r02, tx,
           r10, r11, r12, ty,
           r20, r21, r22, tz, 0., 0., 0., 1. ]
```

**开关**：外参方向正确（求逆填入）后，`estimate_extrinsic` 直接设 **0（锁定）**——实测在线估计在这颗 IMU 上不稳定（外参平移会跑飞米级），锁定反而稳；`estimate_td` 设 **0**，`td` 填 kalibr 输出值（在线 td 估计在相机静止时不可观会跑偏，曾漂到 -94ms 导致公里级发散）。

> ⚠️ **外参方向（2026-09-02 实测，勿踩）**：kalibr 输出的 `T_ci` 标注为「imu0 to cam0」= **T_cam_imu**（以相机为原点看 IMU 在哪）；VINS 的 `body_T_cam0` 要的是 **T_imu_cam**（以 IMU 为原点看相机在哪）——**两者互逆，必须 `np.linalg.inv(T_ci)` 后再填**。直接抄会导致锁定外参时运动后公里级发散；且旋转接近单位阵时方向错误几乎不可见（单位阵的逆还是自己），**只有平移会被悄悄取反**（正确值 z 为正：相机在 IMU 前方 ~1.4cm）。当前稳定配置见 [docs/17](17_稳定配置与运行备忘.md)（含 imu_corrector.py 的 IMU 校正与宽松噪声的结论）。

重启节点：

```bash
ros2 run vins vins_node ws_src/vins_fusion/config/realsense_d435i/realsense_stereo_imu_config.yaml
```

> 现有 [left.yaml](../ws_src/vins_fusion/config/realsense_d435i/left.yaml)（fx≈388.8 @640x480）看起来已是实测值——标定前先核对是不是上次的结果，避免重复填。

### 6.2 ② object_slam 配置（改完**必须 colcon build**）

按 [docs/13](13_分阶段启动与逐级验证.md) 分阶段重启：相机 → VINS → YOLO → object_slam：

## 8. 常见坑

| 坑 | 对策 |
|---|---|
| bag 空 / 话题不存在 | 录前 `ros2 topic list`；话题是**单层** `/camera/...` |
| 录出来没有 IMU 数据 | 必须用 `rs_camera.launch.py`（裸 rs_launch 默认关 IMU/infra） |
| 外参标定发散 | 录 bag 时充分多轴旋转激励（§2.3），禁纯平移 |
| `td` 符号不对 | 试两个符号；`estimate_td: 1` 在线微调兜底 |
| 内参分辨率不对 | kalibr 录制、left/right.yaml、object_slam 全要 **640x480** 一致 |
| object_slam 改了不生效 | 忘了 `colcon build --packages-select object_slam` |
| kalibr 检测不到标定板 | 光照均匀、tagSize 与 april_6x6.yaml 一致 |
| 标定板出画面 | 录制时终端3 预览实时盯 |
