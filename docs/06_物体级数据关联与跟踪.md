# 06 · 物体级数据关联与跟踪

## 1. 目标

给定逐帧的 2D 分割检测，判断"这一帧的检测 A 和上一帧的检测 B 是不是同一个物体"，为每个物体维护一个**跨帧稳定的 track_id**。这是物体级 SLAM 的前提：只有把多帧观测聚合到同一个物体上，才能重建其 3D 椭球并做优化。

## 2. 核心概念

| 概念 | 含义 |
|---|---|
| track | 一个已被跟踪的物体，有唯一 id、类别、最近一次观测状态 |
| 关联（association） | 当前帧检测与已有 track 的匹配 |
| 新生（birth） | 未匹配的检测 → 新 track |
| 消亡（death） | 连续多帧未观测到的 track → 删除 |

## 3. 匹配线索（从易到难）

### 3.1 类别一致（硬约束）

类别不同的检测与 track 直接不匹配。对应 [data_association.cpp](../ws_src/object_slam/src/data_association.cpp#L29-L32) `DataAssociation::matchingCost` 里 `class_id` 不等返回 `inf`。

### 3.2 bbox IoU（主线索）

相邻帧同一物体的 bbox 重叠度（IoU）通常很高（物体运动慢、帧率足够）：

```cpp
double DataAssociation::bboxIoU(const Eigen::Vector4d& a, const Eigen::Vector4d& b) {
  double ix1 = std::max(a(0), b(0)), iy1 = std::max(a(1), b(1));
  double ix2 = std::min(a(2), b(2)), iy2 = std::min(a(3), b(3));
  double inter = std::max(0.0, ix2 - ix1) * std::max(0.0, iy2 - iy1);
  double uni = (a(2)-a(0))*(a(3)-a(1)) + (b(2)-b(0))*(b(3)-b(1)) - inter;
  return uni > 1e-12 ? inter / uni : 0.0;
}
```

> 📄 **源码出处**：[data_association.cpp](../ws_src/object_slam/src/data_association.cpp#L13-L27) 的 `DataAssociation::bboxIoU`（文档为等价改写，真实实现先算 `areaA`/`areaB` 再合并集，见 L22-L25）。

### 3.3 几何线索（进阶，见 docs/07 §5）

把 VINS 的 3D 地图点投影到当前帧，计算**落入检测 mask 的比例**。若某 track 的 3D 点大量落在检测 mask 内，说明二者几何一致，关联置信度更高。

> ⚠️ **当前未实现**（"点投影落入 mask → 属于该物体"的 mask 方案仍为仓库 TODO；3D 点缓存本身已实现——[object_slam_node.cpp](../ws_src/object_slam/src/object_slam_node.cpp#L171-L182) `pointsCallback` 只负责缓存世界点供 docs/07 §5 点-物体关联用，未作为帧间关联线索接入 `associate`）。

### 3.4 马氏距离门控

对已有椭球的物体，把椭球中心投影到当前帧，与检测 bbox 中心比较，用椭球投影椭圆的不确定性做**马氏距离门控**，滤掉几何上不可能的匹配。

**流程**（对每个有有效椭球的 track，在 `associate` 里按每 track 预计算一次）：
1. 用当前帧投影矩阵 `P = K[R_wc | t_wc]` 把椭球投影到图像：`C* = P Q* Pᵀ`；
2. 由原始锥 `C = C*⁻¹` 提取 2D 椭圆：中心 `μ`、协方差 `Σ`（见 docs/07 §2.3），满足**投影椭圆轮廓恰为"单位马氏距离"等值线** `(u-μ)ᵀΣ⁻¹(u-μ) = 1`；
3. **预测点** = 椭球 3D 中心投影 `dehom(P·[c;1])`（`c` 由 `decompose` 得到）；非球形椭球时该点与投影椭圆中心仅差数像素；
4. 检测 bbox 中心换算到像素：`z = (中心·W, 中心·H)`，马氏距离 `d_M² = (z-μ)ᵀΣ⁻¹(z-μ)`；
5. **硬门控**：`d_M² < χ²₂` 才可能匹配，否则视为几何上不可能的匹配直接拒绝。

**只对有"正椭球"的 track 门控**：新 track 的种子锥是秩 3 退化锥（`fromBBoxCone`，恰有一个特征值为 0），由 `isProper()` 排除后跳过门控，退化为纯 IoU 关联。

> ✅ **已实现**（docs/06 本版本落地）：
> - 门控主逻辑在 [data_association.cpp](../ws_src/object_slam/src/data_association.cpp#L34-L99) 的 `DataAssociation::associate`：每 track 预计算投影椭圆（L51-L72），候选检测必须**同时**通过 IoU 门控与马氏门控（L83-L91 `d_M² < chi2_threshold_`）；
> - 椭圆提取 / 投影 / 正椭球检测：`ellipseFromConic`（[quadric.cpp](../ws_src/object_slam/src/quadric.cpp#L67-L96)）、`projectedEllipse`（[quadric.cpp](../ws_src/object_slam/src/quadric.cpp#L98-L114)，含 det/finite 守卫防奇异 NaN）、`isProper`（[quadric.cpp](../ws_src/object_slam/src/quadric.cpp#L116-L130)）；
> - track 携带世界系椭球 Q*：`TrackView::quadric`（[data_association.h](../ws_src/object_slam/include/object_slam/data_association.h#L22)），由 [tracker.cpp](../ws_src/object_slam/src/tracker.cpp#L19) 填充；

## 4. 匹配算法

骨架用**贪心最近邻**（见 `data_association.cpp`）：对每个 track 找代价最小的未占用检测，候选必须**同时通过两道门控**才被接受 —— IoU 门控要求 `cost < 1 - iou_threshold`（默认 `iou_threshold = 0.3`）；马氏门控（§3.4，仅对有有效椭球的 track）要求检测中心 `d_M² < χ²₂`（默认 5.991）。工程上更优的是**匈牙利算法**（全局最优分配），可引入 `scipy.optimize.linear_sum_assignment` 或自己实现 Kuhn–Munkres（当前为 TODO）。

```
算法：关联(detections, tracks, P)
  for each track:
    若有有效椭球: 用 P 预计算投影椭圆中心 μ 与协方差 Σ（像素系）
    对每个未匹配的 detection 计算 cost（类别不一致 -> inf）
    候选需通过两道门控：
      IoU 门控   cost < 1 - iou_threshold
      马氏门控   有椭球时 d_M² = (z-μ)ᵀΣ⁻¹(z-μ) < χ²₂（z=检测中心像素）
    取通过门控且 cost 最小的 detection 作为匹配
  未匹配的 detection -> 新 track
  未匹配的 track -> 未观测计数 +1，超过阈值 -> 删除
```

> 📄 对应 [data_association.cpp](../ws_src/object_slam/src/data_association.cpp#L34-L103) 的 `DataAssociation::associate`（贪心最近邻；IoU 门控 `cost < 1 - iou_threshold_`，阈值由 [data_association.h](../ws_src/object_slam/include/object_slam/data_association.h#L37) 的 `setIoUThreshold` 配置；马氏门控见 §3.4，[data_association.cpp](../ws_src/object_slam/src/data_association.cpp#L51-L91)）。
>
> 帧级跟踪主循环（关联 → 匹配 + EMA → 新生 → 消亡）在 `Tracker::updateFrame`（[tracker.cpp](../ws_src/object_slam/src/tracker.cpp#L8-L62)），由 node 每帧调用（[object_slam_node.cpp](../ws_src/object_slam/src/object_slam_node.cpp#L117)）。
>
> "匈牙利算法 / 几何线索(§3.3)" 仍为仓库 TODO 增强项（[data_association.cpp](../ws_src/object_slam/src/data_association.cpp#L101-L102) 注释）；**马氏距离门控(§3.4) 已实现**。

## 5. 生命周期管理

在 `ObjectMap::markObserved / prune` 里维护，由 `Tracker::updateFrame` 每帧驱动（匹配→`markObserved`，帧末→`prune`）：

```cpp
void ObjectMap::markObserved(int id, int frame_id, int min_observations) {
  e.observations += 1;
  e.last_seen = frame_id;
  e.valid = e.observations >= min_observations;  // 观测足够才输出
}

void ObjectMap::prune(int current_frame, int max_miss) {
  // 超过 max_miss 帧未观测的物体删除
}
```

> 📄 **源码出处**：[object_map.cpp](../ws_src/object_slam/src/object_map.cpp#L39-L45) 的 `ObjectMap::markObserved`（`min_observations` 由参数传入，不再写死）、[object_map.cpp](../ws_src/object_slam/src/object_map.cpp#L47-L55) 的 `ObjectMap::prune`。调用点在 [tracker.cpp](../ws_src/object_slam/src/tracker.cpp#L33)（匹配→markObserved）、[tracker.cpp](../ws_src/object_slam/src/tracker.cpp#L50)（帧末→prune）。`ObjectMap::add` 见 [object_map.cpp](../ws_src/object_slam/src/object_map.cpp#L10-L27)，删除的 id 会被回收复用（见 §6）。

## 6. 遮挡与消失处理

- **短暂遮挡**：track 未匹配但不立即删除，靠 `max_missed_frames` 容忍。已实现：每帧帧末 [tracker.cpp](../ws_src/object_slam/src/tracker.cpp#L50) 调 `prune`，超期才删。
- **重新出现**：若删除前又匹配上，恢复跟踪。已实现：**所有存活 track**（含正在被遮挡的）都参与关联（[tracker.cpp](../ws_src/object_slam/src/tracker.cpp#L11-L21)），物体重新出现时能匹配回原 id，而非新建（有单测覆盖）。
- **id 复用**：删除后 id 可复用。已实现：`ObjectMap::add` 优先从**空闲列表**取被回收的 id（[object_map.cpp](../ws_src/object_slam/src/object_map.cpp#L10-L27)），`erase` 时回收（[object_map.cpp](../ws_src/object_slam/src/object_map.cpp#L35-L37)）。⚠️ 原 `entries_.size()` 分配法在删除后会与现存 id 冲突、覆盖物体，已修复。
- **分割抖动**：YOLO 帧间 mask 抖动会导致 bbox 抖动，对 track 的 bbox 做**指数平滑**（EMA）再用于关联。已实现：匹配时 `bbox_smoothed = ema_alpha * 检测bbox + (1-ema_alpha) * 旧值`（[tracker.cpp](../ws_src/object_slam/src/tracker.cpp#L35)），平滑状态存在 [object_map.h](../ws_src/object_slam/include/object_slam/object_map.h#L18) 的 `ObjectEntry::bbox_smoothed`，权重 `ema_alpha` 为参数（默认 0.7）。
