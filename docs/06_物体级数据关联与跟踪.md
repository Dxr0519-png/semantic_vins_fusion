# 06 · 物体级数据关联与跟踪

## 1. 目标

给定逐帧的 2D 分割检测，判断"这一帧的检测 A 和上一帧的检测 B 是不是同一个物体"，为每个物体维护一个**跨帧稳定的 track_id**。这是物体级 SLAM 的前提：只有把多帧观测聚合到同一个物体上，才能重建其 3D 椭球并做优化。

## 2. 核心概念

| 概念 | 含义 |
|---|---|
| track | 一个已被跟踪的物体，有唯一 id、类别、最近一次观测状态 |
| 关联（association） | 当前帧检测与已有 track 的匹配 |
| 新生（birth） | 未匹配的检测 → 新 track |
| 消亡（death） | 连续多帧未观测到的 track → 删除 |

## 3. 匹配线索（从易到难）

### 3.1 类别一致（硬约束）

类别不同的检测与 track 直接不匹配。对应 [data_association.cpp](../ws_src/object_slam/src/data_association.cpp#L25-L28) `DataAssociation::matchingCost` 里 `class_id` 不等返回 `inf`。

### 3.2 bbox IoU（主线索）

相邻帧同一物体的 bbox 重叠度（IoU）通常很高（物体运动慢、帧率足够）：

```cpp
double DataAssociation::bboxIoU(const Eigen::Vector4d& a, const Eigen::Vector4d& b) {
  double ix1 = std::max(a(0), b(0)), iy1 = std::max(a(1), b(1));
  double ix2 = std::min(a(2), b(2)), iy2 = std::min(a(3), b(3));
  double inter = std::max(0.0, ix2 - ix1) * std::max(0.0, iy2 - iy1);
  double uni = (a(2)-a(0))*(a(3)-a(1)) + (b(2)-b(0))*(b(3)-b(1)) - inter;
  return uni > 1e-12 ? inter / uni : 0.0;
}
```

> 📄 **源码出处**：[data_association.cpp](../ws_src/object_slam/src/data_association.cpp#L9-L23) 的 `DataAssociation::bboxIoU`（文档为等价改写，真实实现先算 `areaA`/`areaB` 再合并集，见 L18-21）。

### 3.3 几何线索（进阶，见 docs/07 §5）

把 VINS 的 3D 地图点投影到当前帧，计算**落入检测 mask 的比例**。若某 track 的 3D 点大量落在检测 mask 内，说明二者几何一致，关联置信度更高。

> ⚠️ **当前未实现**（仓库 TODO，见 [object_slam_node.cpp](../ws_src/object_slam/src/object_slam_node.cpp#L148-L152) `pointsCallback` 的空实现；依赖 docs/07 §5 的 3D 点缓存与 mask 传入）。

### 3.4 马氏距离门控

对已有椭球的物体，把椭球中心投影到当前帧，与检测 bbox 中心比较，用椭球投影椭圆的不确定性做**马氏距离门控**，滤掉几何上不可能的匹配。

## 4. 匹配算法

骨架用**贪心最近邻**（见 `data_association.cpp`）：对每个 track 找代价最小的未占用检测，且只接受 **IoU 高于门控阈值**（`cost < 1 - iou_threshold`，默认 `iou_threshold = 0.3`）的匹配。工程上更优的是**匈牙利算法**（全局最优分配），可引入 `scipy.optimize.linear_sum_assignment` 或自己实现 Kuhn–Munkres（当前为 TODO）。

```
算法：关联(detections, tracks)
  for each track:
    对每个未匹配的 detection 计算 cost（类别不一致 -> inf）
    取 cost 最小的 detection 作为匹配（若 cost < 阈值）
  未匹配的 detection -> 新 track
  未匹配的 track -> 未观测计数 +1，超过阈值 -> 删除
```

> 📄 对应 [data_association.cpp](../ws_src/object_slam/src/data_association.cpp#L30-L58) 的 `DataAssociation::associate`（贪心最近邻 L39-53；IoU 门控 `cost < 1 - iou_threshold_` 在 L39/L54，阈值由 [data_association.h](../ws_src/object_slam/include/object_slam/data_association.h#L34) 的 `setIoUThreshold` 配置）。
>
> 帧级跟踪主循环（关联 → 匹配 + EMA → 新生 → 消亡）在新增的 `Tracker::updateFrame`（[tracker.cpp](../ws_src/object_slam/src/tracker.cpp#L8-L48)），由 node 每帧调用（[object_slam_node.cpp](../ws_src/object_slam/src/object_slam_node.cpp#L108)）。
>
> "匈牙利算法 / 几何线索(§3.3) / 马氏距离门控(§3.4)" 仍为仓库 TODO 增强项（[data_association.cpp](../ws_src/object_slam/src/data_association.cpp#L60-L61) 注释）。

## 5. 生命周期管理

在 `ObjectMap::markObserved / prune` 里维护，由 `Tracker::updateFrame` 每帧驱动（匹配→`markObserved`，帧末→`prune`）：

```cpp
void ObjectMap::markObserved(int id, int frame_id, int min_observations) {
  e.observations += 1;
  e.last_seen = frame_id;
  e.valid = e.observations >= min_observations;  // 观测足够才输出
}

void ObjectMap::prune(int current_frame, int max_miss) {
  // 超过 max_miss 帧未观测的物体删除
}
```

> 📄 **源码出处**：[object_map.cpp](../ws_src/object_slam/src/object_map.cpp#L39-L45) 的 `ObjectMap::markObserved`（`min_observations` 由参数传入，不再写死）、[object_map.cpp](../ws_src/object_slam/src/object_map.cpp#L47-L53) 的 `ObjectMap::prune`。调用点在 [tracker.cpp](../ws_src/object_slam/src/tracker.cpp#L31)（匹配→markObserved）、[tracker.cpp](../ws_src/object_slam/src/tracker.cpp#L46)（帧末→prune）。`ObjectMap::add` 见 [object_map.cpp](../ws_src/object_slam/src/object_map.cpp#L10-L22)，删除的 id 会被回收复用（见 §6）。

**参数**：`min_observations = 3`（避免单帧噪声）、`max_missed_frames = 30`（应对短暂遮挡）——已实现为 ROS 参数，由 [object_slam_node.cpp](../ws_src/object_slam/src/object_slam_node.cpp#L25-L26) 读取并传给 tracker（L44-45），默认值见 [object_slam.yaml](../ws_src/object_slam/config/object_slam.yaml)。

## 6. 遮挡与消失处理

- **短暂遮挡**：track 未匹配但不立即删除，靠 `max_missed_frames` 容忍。已实现：每帧帧末 [tracker.cpp](../ws_src/object_slam/src/tracker.cpp#L46) 调 `prune`，超期才删。
- **重新出现**：若删除前又匹配上，恢复跟踪。已实现：**所有存活 track**（含正在被遮挡的）都参与关联（[tracker.cpp](../ws_src/object_slam/src/tracker.cpp#L11-L19)），物体重新出现时能匹配回原 id，而非新建（有单测覆盖）。
- **id 复用**：删除后 id 可复用。已实现：`ObjectMap::add` 优先从**空闲列表**取被回收的 id（[object_map.cpp](../ws_src/object_slam/src/object_map.cpp#L10-L22)），`erase` 时回收（[object_map.cpp](../ws_src/object_slam/src/object_map.cpp#L35-L37)）。⚠️ 原 `entries_.size()` 分配法在删除后会与现存 id 冲突、覆盖物体，已修复。
- **分割抖动**：YOLO 帧间 mask 抖动会导致 bbox 抖动，对 track 的 bbox 做**指数平滑**（EMA）再用于关联。已实现：匹配时 `bbox_smoothed = ema_alpha * 检测bbox + (1-ema_alpha) * 旧值`（[tracker.cpp](../ws_src/object_slam/src/tracker.cpp#L33)），平滑状态存在 [object_map.h](../ws_src/object_slam/include/object_slam/object_map.h#L18) 的 `ObjectEntry::bbox_smoothed`，权重 `ema_alpha` 为参数（默认 0.7）。
