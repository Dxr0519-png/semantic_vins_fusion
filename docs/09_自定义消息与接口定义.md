# 09 · 自定义消息与接口定义

## 1. 设计原则

- **C++/Python 共用**：所有跨节点消息定义在 `semantic_interfaces` 包（`.msg` 文件），ROS2 自动生成两套语言绑定，避免 Python 节点与 C++ 节点之间类型不一致。
- **掩码与检测分离**：大体积二值掩码内嵌在 `Detection2D` 里，随检测一起发；带宽敏感场景可下采样掩码（见 §4）。
- **时间对齐**：每条 `Detection2D`/`Detection2DArray` 都带原图帧的 `header.stamp`，供 object_slam 与 VINS 关键帧按时间对齐。

## 2. 消息清单

| 消息 | 用途 | 方向 |
|---|---|---|
| `InstanceMask` | 二值掩码 | yolo_seg_ros → object_slam |
| `Detection2D` | 单个检测（bbox+mask+类） | 同上 |
| `Detection2DArray` | 一帧所有检测 | 同上 |
| `Object3D` | 一个 3D 物体（对偶二次曲面） | object_slam → rviz/外部 |
| `ObjectMap` | 物体地图 | 同上 |

## 3. 字段说明（关键字段）

### 3.1 Detection2D

```text
std_msgs/Header header   # stamp = 原图时间戳
int32  class_id          # COCO 类别 id
string class_name
float32 score
float32 x_min/y_min/x_max/y_max   # 归一化 bbox（[0,1] 相对原图宽高）
InstanceMask mask
```

> 归一化 bbox 与分辨率无关，object_slam 反投影时再乘上原图宽高。

### 3.2 Object3D

```text
int32 id                 # track_id
int32 class_id
string class_name
float32 confidence
float64[16] dual_quadric # 4x4 对称矩阵 Q*，行主序
geometry_msgs/Point center
float64[3] scale         # 半轴 (rx,ry,rz)
```

**对偶二次曲面约定**（详见 [`docs/07`](07_对偶二次曲面物体重建.md)）：

- 9 自由度对称矩阵，行主序平铺成 16 元素数组；
- 点 `x̃` 在椭球上满足 `x̃ᵀ Q x̃ = 0`（此处 Q 为**原始二次曲面**）；
- 对偶形式 `Q* = adj(Q)`，满足 `πᵀ Q* π = 0`（π 为切平面），用于投影/优化；
- 本消息字段 `dual_quadric` 存 **Q***。

## 4. 带宽与实时性考量

| 项 | 建议 |
|---|---|
| 掩码分辨率 | 原图 848×480 的 mask 每帧约 400KB；可先缩到 1/4 尺寸，object_slam 反投影时按比例放大 |
| 消息 QoS | YOLO 检测用 `Best effort`（丢帧可接受），VINS 位姿/点云用 `Reliable` |
| 频率 | YOLO 目标 ≥15Hz；object_slam 按关键帧（而非每帧）做关联与优化 |

## 5. 编译

`semantic_interfaces` 是纯消息包，无运行时节点：

```bash
cd /workspace
colcon build --symlink-install --packages-select semantic_interfaces
source install/setup.bash
ros2 interface list | grep semantic
# semantic_interfaces/msg/Detection2DArray
# semantic_interfaces/msg/Detection2D
# semantic_interfaces/msg/InstanceMask
# semantic_interfaces/msg/Object3D
# semantic_interfaces/msg/ObjectMap
```

## 6. 扩展指南

- 新增动态物体类别过滤（如 "person"/"car"）：不需要改消息，object_slam 内按 `class_id` 过滤即可（见 [`docs/05`](05_动态物体特征点剔除.md)）。
- 若后续引入 cuboid 表示：在 `Object3D` 增加 `geometry_msgs/Point[8] corners` 字段，或用独立消息避免破坏兼容性。
