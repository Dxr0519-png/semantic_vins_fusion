# 09 · 自定义消息与接口定义

## 1. 设计原则

- **C++/Python 共用**：所有跨节点消息定义在 `semantic_interfaces` 包（`.msg` 文件），ROS2 自动生成两套语言绑定，避免 Python 节点与 C++ 节点之间类型不一致。
- **掩码与检测分离**：大体积二值掩码内嵌在 `Detection2D` 里，随检测一起发；带宽敏感场景可下采样掩码（见 §5）。
- **时间对齐**：每条 `Detection2D`/`Detection2DArray` 都带原图帧的 `header.stamp`，供 object_slam 与 VINS 关键帧按时间对齐。

## 2. 消息生成机制

`semantic_interfaces` 的消息头文件不是手写的，而是由 `.msg` 文本定义在**构建时自动生成**（rosidl 代码生成器）。

### 2.1 定义 → 生成 → 使用 的流程

```text
ws_src/semantic_interfaces/msg/*.msg     ① 手写 IDL 文本定义
        │ colcon build（rosidl_adapter + rosidl_generator_*）
        ▼
build/semantic_interfaces/rosidl_generator_cpp/semantic_interfaces/msg/*.hpp   ② 生成的 C++ 头文件
install/semantic_interfaces/include/semantic_interfaces/semantic_interfaces/msg/*.hpp
        │ find_package + ament_target_dependencies
        ▼
object_slam 源码：#include <semantic_interfaces/msg/detection2_d_array.hpp>     ③ 使用
```

> 📄 图中 ① 对应 [semantic_interfaces/msg/](../ws_src/semantic_interfaces/msg/) 下 5 个 `.msg`；② 由 [CMakeLists.txt](../ws_src/semantic_interfaces/CMakeLists.txt#L21-L24) 的 `rosidl_generate_interfaces()` + [package.xml](../ws_src/semantic_interfaces/package.xml#L20) 的 `<member_of_group>rosidl_interface_packages</member_of_group>` 触发；③ 示例 include 见 [object_slam_node.h](../ws_src/object_slam/include/object_slam/object_slam_node.h#L10-L12)。

1. **定义**：每个消息一个 `.msg` 文件，见 [semantic_interfaces/msg/](../ws_src/semantic_interfaces/msg/)。
2. **触发**：[semantic_interfaces/CMakeLists.txt](../ws_src/semantic_interfaces/CMakeLists.txt) 里 `rosidl_generate_interfaces()` 列出所有 `.msg`；[package.xml](../ws_src/semantic_interfaces/package.xml) 声明 `<member_of_group>rosidl_interface_packages</member_of_group>`。
3. **生成**：`rosidl_adapter` 把 `.msg` 转成中间 IDL，再由 `rosidl_generator_cpp`（C++ 绑定）、`rosidl_generator_py`（Python 模块）、`rosidl_typesupport_fastrtps/introspection_*`（序列化）生成对应代码。
4. **暴露给节点**：[object_slam/CMakeLists.txt](../ws_src/object_slam/CMakeLists.txt) 中 `find_package(semantic_interfaces REQUIRED)` + `ament_target_dependencies(object_slam_node ... semantic_interfaces)` 把生成头文件目录加入 include path，源码才能直接 `#include`。

### 2.2 命名转换（决定 include 哪个头文件）

`.msg` 文件名（CamelCase）→ C++ 头文件（snake_case），**数字后紧跟的大写字母前插入下划线**：

| `.msg` 定义 | C++ include 头 | C++ 类型 |
|---|---|---|
| `Detection2DArray.msg` | `semantic_interfaces/msg/detection2_d_array.hpp` | `semantic_interfaces::msg::Detection2DArray` |
| `Detection2D.msg` | `semantic_interfaces/msg/detection2_d.hpp` | `semantic_interfaces::msg::Detection2D` |
| `Object3D.msg` | `semantic_interfaces/msg/object3_d.hpp` | `semantic_interfaces::msg::Object3D` |
| `ObjectMap.msg` | `semantic_interfaces/msg/object_map.hpp` | `semantic_interfaces::msg::ObjectMap` |
| `InstanceMask.msg` | `semantic_interfaces/msg/instance_mask.hpp` | `semantic_interfaces::msg::InstanceMask` |

> `2D → 2_d`、`3D → 3_d` 是 rosidl 的固定规则，不是拼写错误。

### 2.3 如何确定要 include 哪个

写/改节点时先看话题类型，用了哪个消息就 include 哪个：

```cpp
// object_slam_node.cpp：订阅检测输入、发布物体地图
create_subscription<semantic_interfaces::msg::Detection2DArray>(...);
create_publisher<semantic_interfaces::msg::ObjectMap>(...);
```

> 📄 **源码出处**：[object_slam_node.cpp](../ws_src/object_slam/src/object_slam_node.cpp#L57-L74) —— `create_subscription<Detection2DArray>` L57-59（`/yolo/detections`）、`create_subscription<Odometry>` L63-65（`/keyframe_pose`，VINS 关键帧位姿）、`create_subscription<PointCloud>` L67-69（`/keyframe_point`）、`create_publisher<ObjectMap>` L71-72（`/object_slam/objects`）、`create_publisher<Path>` L73-74。

对类型 `semantic_interfaces::msg::Detection2DArray` 取 `包/msg/` + 蛇形化小写名，即得到头文件路径。也可在终端确认消息存在及字段：

```bash
source /workspace/install/setup.bash
ros2 interface show semantic_interfaces/msg/Detection2DArray
```

## 3. 消息清单

| 消息 | 用途 | 方向 |
|---|---|---|
| `InstanceMask` | 二值掩码 | yolo_seg_ros → object_slam |
| `Detection2D` | 单个检测（bbox+mask+类） | 同上 |
| `Detection2DArray` | 一帧所有检测 | 同上 |
| `Object3D` | 一个 3D 物体（对偶二次曲面） | object_slam → rviz/外部 |
| `ObjectMap` | 物体地图 | 同上 |

## 4. 字段说明（关键字段）

### 4.1 Detection2D

```text
std_msgs/Header header   # stamp = 原图时间戳
int32  class_id          # COCO 类别 id
string class_name
float32 score
float32 x_min/y_min/x_max/y_max   # 归一化 bbox（[0,1] 相对原图宽高）
InstanceMask mask
```

> 📄 对应 [Detection2D.msg](../ws_src/semantic_interfaces/msg/Detection2D.msg)（实际还有 `InstanceMask` 的 width/height/data 三字段，见 [InstanceMask.msg](../ws_src/semantic_interfaces/msg/InstanceMask.msg)）。

> 归一化 bbox 与分辨率无关，object_slam 反投影时再乘上原图宽高。

### 4.2 Object3D

```text
int32 id                 # track_id
int32 class_id
string class_name
float32 confidence
float64[16] dual_quadric # 4x4 对称矩阵 Q*，行主序
geometry_msgs/Point center
float64[3] scale         # 半轴 (rx,ry,rz)
```

> 📄 对应 [Object3D.msg](../ws_src/semantic_interfaces/msg/Object3D.msg)（实际还带 `std_msgs/Header header`）。

**对偶二次曲面约定**（详见 [`docs/07`](07_对偶二次曲面物体重建.md)）：

- 9 自由度对称矩阵，行主序平铺成 16 元素数组；
- 点 `x̃` 在椭球上满足 `x̃ᵀ Q x̃ = 0`（此处 Q 为**原始二次曲面**）；
- 对偶形式 `Q* = adj(Q)`，满足 `πᵀ Q* π = 0`（π 为切平面），用于投影/优化；
- 本消息字段 `dual_quadric` 存 **Q***。

## 5. 带宽与实时性考量

| 项 | 建议 |
|---|---|
| 掩码分辨率 | 原图 848×480 的 mask 每帧约 400KB；可先缩到 1/4 尺寸，object_slam 反投影时按比例放大 |
| 消息 QoS | YOLO 检测用 `Best effort`（丢帧可接受），VINS 位姿/点云用 `Reliable` |
| 频率 | YOLO 目标 ≥15Hz；object_slam 按关键帧（而非每帧）做关联与优化 |

## 6. 编译

`semantic_interfaces` 是纯消息包，无运行时节点：

```bash
cd /workspace
colcon build --symlink-install --packages-select semantic_interfaces
source install/setup.bash
ros2 interface list | grep semantic
# semantic_interfaces/msg/Detection2DArray
# semantic_interfaces/msg/Detection2D
# semantic_interfaces/msg/InstanceMask
# semantic_interfaces/msg/Object3D
# semantic_interfaces/msg/ObjectMap
```

> 📄 消息生成声明见 [semantic_interfaces/CMakeLists.txt](../ws_src/semantic_interfaces/CMakeLists.txt#L13-L24) 的 `msg_files` 列表与 `rosidl_generate_interfaces()`。

## 7. 扩展指南

- 新增动态物体类别过滤（如 "person"/"car"）：不需要改消息，object_slam 内按 `class_id` 过滤即可（见 [`docs/05`](05_动态物体特征点剔除.md)）。
- 若后续引入 cuboid 表示：在 `Object3D` 增加 `geometry_msgs/Point[8] corners` 字段，或用独立消息避免破坏兼容性。
