# 00 · 项目概述与总体架构

## 1. 项目目标

传统 VINS-Fusion 在动态场景下存在两个问题：

1. **定位退化**：行人、车辆等动态物体上的特征点违反"静态世界"假设，导致视觉惯性里程计漂移甚至发散。
2. **无物体语义**：输出的只是稀疏点云，无法回答"场景里有什么物体、在哪里、多大"。

本项目在 VINS-Fusion 之上叠加 YOLOv8-seg 实例分割，实现**物体级语义 SLAM**：

- 用语义分割识别并跟踪场景中的物体（椅子、箱子、显示器等）；
- 用**对偶二次曲面（椭球）**为每个物体建立 3D 表示（位姿 + 尺度）；
- 通过物体级联合优化，同时约束相机位姿与物体参数，输出带语义标签的物体地图。

## 2. 为什么用"对偶二次曲面"表达物体

| 表示 | 优点 | 缺点 |
|---|---|---|
| 点云簇 | 简单 | 无参量化、难优化、噪声大 |
| 3D 包围盒 cuboid | 直观、可度量 | 8 角点估计难、退化解多 |
| **对偶二次曲面（椭球）** | 9 自由度、可从 bbox 反投影锥初始化、可写进因子图优化 | 椭球近似、细节损失 |

对偶二次曲面是 QuadricSLAM / SO-SLAM / OA-SLAM 等物体级 SLAM 的主流选择，与 2D 检测框有天然的投影对应关系（椭球投影为一个椭圆，与 bbox 内切），非常适合本项目的学习与实现目标。

## 3. 系统总体架构

```
                        ┌──────────────────────────────────────────────┐
                        │              RealSense D435i                │
                        │   左目 / 右目 / IMU(6轴)  (硬件同步)          │
                        └───────┬───────────────┬──────────────────────┘
                                │ color + depth │ gray + IMU
                                ▼               ▼
                    ┌───────────────┐   ┌──────────────────┐
                    │ yolo_seg_ros  │   │   vins_fusion     │
                    │ (Python/TRT)  │   │   (ROS2 移植)     │
                    │ 输出:         │   │ 输出:             │
                    │ Detection2D[] │   │  - odometry       │
                    │  - bbox       │   │  - path           │
                    │  - mask       │   │  - point_cloud    │
                    │  - class      │   │  - keyframe_pose  │
                    └──────┬────────┘   │  - map_points     │
                           │            └─────────┬─────────┘
                           │                      │
                           └──────────┬───────────┘
                                      ▼
                          ┌──────────────────────────┐
                          │      object_slam         │
                          │  ① 数据关联 (track_id)    │
                          │  ② 椭球初始化/重建        │
                          │  ③ 联合优化 (g2o 因子图)  │
                          └──────────┬───────────────┘
                                     ▼
                        ┌──────────────────────────┐
                        │ 输出: 物体地图 ObjectMap   │
                        │  - Object3D[] (id/类/椭球)│
                        │  - 优化后轨迹            │
                        └──────────────────────────┘
```

## 4. ROS2 话题与数据流

| 话题 | 类型 | 方向 |
|---|---|---|
| `/camera/color/image_raw` | `sensor_msgs/Image` | D435i → yolo_seg_ros |
| `/camera/infra1/image_rect_raw` | `sensor_msgs/Image` | D435i → vins_fusion（左目灰度） |
| `/camera/infra2/image_rect_raw` | `sensor_msgs/Image` | D435i → vins_fusion（右目灰度） |
| `/camera/imu` | `sensor_msgs/Imu` | D435i → vins_fusion |
| `/yolo/detections` | `semantic_interfaces/Detection2DArray` | yolo_seg_ros → object_slam |
| `/odometry` | `nav_msgs/Odometry` | vins_fusion → object_slam / 外部 |
| `/path` | `nav_msgs/Path` | vins_fusion → rviz |
| `/point_cloud` | `sensor_msgs/PointCloud` | vins_fusion → object_slam |
| `/keyframe_pose` | `nav_msgs/Odometry` | vins_fusion → object_slam |
| `/keyframe_point` | `sensor_msgs/PointCloud` | vins_fusion → object_slam |
| `/object_slam/objects` | `semantic_interfaces/ObjectMap` | object_slam → rviz / 外部 |
| `/object_slam/trajectory` | `nav_msgs/Path` | object_slam → rviz |

> 消息精确定义见 [`docs/09`](09_自定义消息与接口定义.md)。

## 5. 模块划分与依赖

| 模块 | 语言 | 关键依赖 | 职责 |
|---|---|---|---|
| `semantic_interfaces` | — | `rosidl_default_generators` | 消息协议 |
| `yolo_seg_ros` | Python | `rclpy`、`ultralytics`、`cv_bridge` | 2D 分割推理 |
| `vins_fusion` | C++ | `Eigen`、`OpenCV`、`ceres` | VIO 前/后端 |
| `object_slam` | C++ | `Eigen`、`g2o`、`rclcpp` | 物体级重建与优化 |

## 6. 分阶段实施路线（与文档对应）

| 阶段 | 里程碑 | 文档 |
|---|---|---|
| P0 | 容器环境跑通（GPU/ROS2/RealSense） | 01 |
| P1 | VINS-Fusion 出里程计 + YOLO 出分割 | 02、03、04 |
| P2 | 动态物体特征点剔除（中间基线） | 05 |
| P3 | 物体级数据关联（多帧跟踪） | 06 |
| P4 | 对偶二次曲面重建 | 07 |
| P5 | 物体级联合优化 | 08 |
| P6 | 端到端验证与评测 | 10 |

每个阶段都有可独立验证的输出，建议**严格按顺序推进**，不要跳过 P0~P2。

## 7. 坐标系约定

- 世界系 `world`：VINS-Fusion 第一帧 IMU 系（重力对齐）。
- 相机系 `camera`：左目红外相机系（VINS 使用），与 D435i 出厂 `infra1` 对齐。
- 物体系 `object`：椭球中心 + 轴对齐（在 `world` 系下表达，9 参数）。

> 相机-IMU 外参与标定见 [`docs/04`](04_传感器时间同步与内外参标定.md)。
